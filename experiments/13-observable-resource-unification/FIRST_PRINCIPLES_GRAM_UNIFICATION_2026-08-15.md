## 2. Master positive pairing

Let `H` be a Hilbert space of elementary signal, excitation, or innovation degrees of freedom. Let

```math
M:\mathcal H\to\mathcal Y
```

be a bounded linear coupling/readout map into an observation space `Y`. Define its positive Gram/effect operator

```math
\boxed{G=M^\dagger M\succeq0.}
```

For any positive trace-class excitation/activity operator

```math
X\succeq0,
```

define

```math
\boxed{
\mathcal Q_G[X]
=\operatorname{Tr}(GX)
=\operatorname{Tr}(MXM^\dagger).

```

This expression contains several familiar cases:

- `X=|s><s|`: quadratic performance of a deterministic task vector;
- `X=rho`: acceptance probability / response of a mixed excitation ensemble under a positive effect;

- `X=rho_th`: response weight supported by thermally occupied microscopic states.

The generic algebra is elementary. Any candidate novelty must come from the detector-specific closure obtained by identifying the physically correct `G`, `X`, task family, and resource constraints.

## 3. Spectral sandwich theorem

Let `S=supp(X)` and `P_S` be its support projector. Define

```math
\lambda_+(G;S)
=\sup_{\psi\in S,\|\psi\|=1}\langle\psi|G|\psi\rangle,
```

and

```math
\lambda_-(G;S)
=\inf_{\psi\in S,\|\psi\|=1}\langle\psi|G|\psi\rangle.
```

Equivalently, if `G=M^dagger M`, these are the squared largest and smallest singular values of `M` restricted to `S`.

Because

```math
\lambda_-P_S\preceq P_SGP_S\preceq\lambda_+P_S,
```

multiplication by `X^{1/2}` and taking the trace gives

```math
\boxed{
\lambda_-\operatorname{Tr}X
\le
\operatorname{Tr}(GX)
\le
\lambda_+\operatorname{Tr}X.
}
```

The constants are tight.

### Consequence A — inverse resource floor

If an observable quadratic response `R=Tr(GX)` is required and `lambda_+` is finite,

```math
\boxed{
\operatorname{Tr}X\ge R/\lambda_+.
}
```

Thus a finite **upper coupling capacity** converts required response into a minimum internal resource.

### Consequence B — observability floor

If `lambda_->0`, then any nonzero internal resource produces a minimum observable response:

```math
\boxed{
R\ge\lambda_-\operatorname{Tr}X.
}
```

If `lambda_-=0`, no strictly positive universal output floor follows from internal activity alone. There are invisible or arbitrarily weakly observed directions.

This creates an exact capacity/observability duality:

```text
largest singular value  ->  response cannot be obtained with arbitrarily little resource;
smallest singular value ->  internal resource cannot be hidden from the readout.
```

## 4. Pure-task theorem and universal detector ordering

For a deterministic task vector `s`, set

```math
X_s=|s\rangle\langle s|.
```

Then

```math
\boxed{
J_G(s)=\langle s|G|s\rangle.
}
```

For two detectors `A,B` represented on a common task space by positive information operators `G_A,G_B`, detector A is at least as informative as B for **every** deterministic task vector in subspace `S` iff

```math
\boxed{
P_S(G_A-G_B)P_S\succeq0.
}
```

If the difference is indefinite, the Rayleigh quotient immediately gives two task vectors `s_+` and `s_-` with opposite detector ordering:

```math
J_A(s_+)>J_B(s_+),
\qquad
J_A(s_-)<J_B(s_-).
```

Therefore universal detector ranking is an operator-ordering problem, not generally a scalar-ranking problem.

### Scalar completeness criterion

Suppose one scalar `c` is claimed to characterize normalized performance identically for every unit task vector in `S`:

```math
\langle s|G|s\rangle=c
\qquad\forall\,s\in S,\ \|s\|=1.
```

By the polarization identity this is equivalent to

```math
\boxed{P_SGP_S=cP_S.}
```

Thus a single scalar is exactly task-complete only when the induced detector metric is isotropic on the relevant task subspace (or the task subspace is one-dimensional).

This is the cleanest abstract form of the lesson behind Experiment 01.



```math
\boxed{
```
