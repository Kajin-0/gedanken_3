# Step 05 — Exact SNR Accumulation by a Deadline

**Date:** 2026-08-11 12:18 EDT  
**Status:** DERIVED under explicit linear/additive-noise assumptions. The exact finite-window quantity is a restricted noise-covariance quadratic form. In white noise it reduces to cumulative signal-energy fraction. No universal replacement metric is claimed.

---

## 1. Question

For a finite observation time, what is the simplest exact quantity that measures how much of a detector's full matched-filter SNR has become available by a deadline `T`?

The desired quantity should:

- compare finite observation with the detector's own full-observation limit;
- retain colored-noise correlations correctly;
- reduce to the obvious cumulative-energy result in white noise;
- not assume that `D*(f)` magnitude alone is sufficient;
- not be promoted prematurely to a universal detector scalar.

---

## 2. Finite-window measurement in the time domain

Let the detector output be

```math
y(t)=s(t)+n(t),
```

where `s(t)` is the deterministic output signal generated by the specified optical waveform and detector, and `n(t)` is zero-mean additive noise.

Observe only the interval

```math
W_T=[0,T].
```

Let the noise covariance kernel restricted to this interval be

```math
C_T(t,t')
=E[n(t)n^*(t')],
\qquad t,t'\in[0,T].
```

For an arbitrary linear statistic

```math
z_q=\int_0^T q^*(t)y(t)dt,
```

its squared SNR is

```math
\rho_q^2(T)
=
\frac{
\left|\int_0^T q^*(t)s(t)dt\right|^2
}{
\int_0^T\int_0^T
q^*(t)C_T(t,t')q(t')dt\,dt'
}.
```

Assume the covariance operator is positive definite on the relevant signal subspace.

---

## 3. Exact maximum SNR available by time T

Using the covariance-weighted Cauchy-Schwarz inequality, the maximizing finite-window filter is

```math
q_T\propto C_T^{-1}s_T,
```

where `s_T` is the signal restricted to `[0,T]`.

Therefore the exact finite-window maximum linear SNR is

```math
\boxed{
\rho_T^2
=\langle s_T,C_T^{-1}s_T\rangle
}
```

or explicitly

```math
\boxed{
\rho_T^2
=
\int_0^T\int_0^T
s^*(t)C_T^{-1}(t,t')s(t')dt\,dt'.
}
```

This is the finite-record analogue of the full-observation matched-filter result.

For stationary noise and full observation,

```math
\rho_\infty^2
=
\int_{-\infty}^{\infty}
\frac{|S(f)|^2}{S_n(f)}df.
```

Important subtlety: for colored noise, one must not generally replace the exact finite-window expression by simply whitening the infinite record and then truncating it. Restriction to a finite interval and inversion/whitening of the covariance need not commute. The restricted covariance operator `C_T` is the exact object.

---

## 4. Define the SNR-squared availability fraction

Define

```math
\boxed{
\eta(T)
\equiv
\frac{\rho_T^2}{\rho_\infty^2}.
}
```

Interpretation:

```text
eta(T) = fraction of the detector's full matched-filter SNR^2
         that is accessible using data available by deadline T.
```

The corresponding fraction of SNR amplitude is

```math
\frac{\rho_T}{\rho_\infty}=\sqrt{\eta(T)}.
```

Squared SNR is the natural normalized quantity because independent whitened signal components contribute additively to `rho^2`, not to `rho`.

This is a task- and protocol-specific functional, not an intrinsic scalar detector figure of merit.

---

## 5. General properties

For nested observation intervals `[0,T]`:

```math
0\le\eta(T)\le1.
```

Also,

```math
T_2>T_1
\quad\Rightarrow\quad
\rho_{T_2}^2\ge\rho_{T_1}^2,
```

because the longer-record estimator may always ignore the extra data and reproduce the shorter-record optimum.

Hence

```math
\boxed{
\eta(T)\ \text{is nondecreasing in }T.
}
```

Under ordinary convergence assumptions,

```math
\lim_{T\to\infty}\eta(T)=1.
```

Thus `eta(T)` is an SNR-accumulation curve rather than one number.

If constant latency is considered irrelevant, a separate alignment-compensated version may be defined by maximizing `rho^2` over all windows of duration `T`; this is a different protocol and should not be silently substituted for the deadline definition above.

---

## 6. White-noise simplification

If output noise is white with covariance

```math
C(t,t')=N\delta(t-t'),
```

then

```math
C_T^{-1}(t,t')=\frac1N\delta(t-t')
```

inside the observation interval, giving

```math
\boxed{
\rho_T^2
=\frac1N\int_0^T|s(t)|^2dt.
}
```

For a causal signal with finite total energy,

```math
\rho_\infty^2
=\frac1N\int_0^\infty|s(t)|^2dt,
```

so

```math
\boxed{
\eta(T)
=
\frac{\int_0^T|s(t)|^2dt}
{\int_0^\infty|s(t)|^2dt}.
}
```

In white noise, the SNR-squared availability is exactly the cumulative fraction of output signal energy.

---

## 7. Return to a one-pole fast/slow response

Take the simplest causal exponential output waveform

```math
s_\tau(t)=S_0e^{-t/\tau}u(t).
```

The amplitude `S_0` cancels in the normalized accumulation fraction. In white output noise,

```math
\eta_\tau(T)
=
\frac{\int_0^T e^{-2t/\tau}dt}
{\int_0^\infty e^{-2t/\tau}dt}.
```

Therefore

```math
\boxed{
\eta_\tau(T)=1-e^{-2T/\tau}.
}
```

This gives an exact temporal interpretation of the response time in this minimal pulse model.

For the original thought-experiment values

```math
\tau_A=1\ \mathrm{ns},
\qquad
\tau_B=1\ \mathrm{s},
```

at the same deadline `T=1 us`,

```math
\eta_A(1\ \mathrm{us})
=1-e^{-2000}
\approx1,
```

while

```math
\eta_B(1\ \mathrm{us})
=1-e^{-2\times10^{-6}}
\approx2.0\times10^{-6}.
```

Thus, relative to each detector's own eventual matched-filter `SNR^2`, essentially all of A's is available by `1 us`, while only about two parts per million of B's is available.

This comparison concerns the **fraction of eventual SNR^2**, not necessarily equal absolute eventual SNR. If the two detectors are additionally normalized to have equal `rho_infinity`, then the same `eta(T)` ratio directly determines their finite-deadline SNR difference.

---

## 8. SNR-acquisition times

For any chosen fraction `q` with `0<q<1`, define the task-specific acquisition time

```math
T_q
=\inf\{T:\eta(T)\ge q\}.
```

For the one-pole exponential example,

```math
\boxed{
T_q=-\frac{\tau}{2}\ln(1-q).
}
```

Examples:

```text
q = 0.50 -> T_q = 0.3466 tau
q = 0.90 -> T_q = 1.1513 tau
q = 0.95 -> T_q = 1.4979 tau
q = 0.99 -> T_q = 2.3026 tau
```

These are thresholds on accumulated `SNR^2`, not arbitrary rise-time conventions.

They are still waveform/noise/protocol dependent and therefore must not be advertised as universal detector constants.

---

## 9. First nontrivial consequence

**DERIVED / CONDITIONAL:** the simplest exact finite-time object is not another bandwidth number but the cumulative optimum-SNR functional

```math
\rho_T^2=\langle s_T,C_T^{-1}s_T\rangle,
```

or its dimensionless normalization

```math
\boxed{
\eta(T)=\rho_T^2/\rho_\infty^2.
}
```

This separates two physically different questions:

```text
How much total matched-filter SNR is ultimately available?
    -> rho_infinity

How quickly does that SNR become available?
    -> eta(T)
```

Two detectors may therefore agree in asymptotic detectability while differing in SNR-acquisition dynamics.

This formalizes, without assuming that faster is universally better, the intuition that finite-time detection depends on the rate at which recoverable signal-to-noise information becomes available.

---

## 10. What has been established

- **DERIVED:** exact finite-record maximum linear SNR is `rho_T^2=<s_T,C_T^{-1}s_T>`.
- **DEFINED:** `eta(T)=rho_T^2/rho_infinity^2` is the fraction of full matched-filter `SNR^2` available by deadline `T`.
- **DERIVED:** `eta(T)` is bounded between 0 and 1 and is nondecreasing for nested observation windows.
- **DERIVED:** in white noise, `eta(T)` is exactly cumulative signal-energy fraction.
- **DERIVED:** for a one-pole exponential waveform, `eta_tau(T)=1-exp(-2T/tau)`.
- **DERIVED:** for `tau_A=1 ns`, `tau_B=1 s`, and `T=1 us`, the fractions are approximately `1` and `2e-6`, respectively.

---

## 11. What has not been established

- `eta(T)` is not claimed to be a universal replacement for `D*`.
- No universal detector ranking follows from `eta(T)` without specifying waveform, noise, event alignment, and deadline protocol.
- No claim that the one-pole exponential example describes all fast or slow photodetectors.
- No treatment yet of probability of detection at fixed false-alarm rate.
- No signal-dependent shot noise, saturation, dead time, nonlinear response, or nonstationary noise.
- No novelty claim.
