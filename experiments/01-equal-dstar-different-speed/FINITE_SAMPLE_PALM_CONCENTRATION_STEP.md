# Step 42 — Finite-Sample Concentration of the Occupation-Palm Node Estimator

**Date:** 2026-08-12 15:25 EDT  
**Status:** DERIVED / RIGOROUS FINITE-GRID CONCENTRATION TEST / NEGATIVE RESULT / REJECTED SHORTCUT / REFINEMENT / OPEN. Step 41 removed the empirical continuous-`q` interpolation allowance, leaving the finite-sample occupation-Palm node estimates as the main statistical gap. This step asks whether the existing raw first-moment estimator can simply be wrapped in a rigorous empirical-Bernstein confidence bound. It cannot: the inverse-duration weight has a very large formal range because the finite-grid implementation allows component duration down to `delta_t/2`. At the rough endpoint, Maurer-Pontil empirical Bernstein gives a 95% one-sided radius of about `0.245 alpha` for the existing `50000` paths, overwhelmingly larger than the available margin. The obstruction is almost entirely the `B/n` range term, not the observed variance. A duration-truncated cluster decomposition reduces the support by orders of magnitude while preserving an exact false-alarm upper decomposition; the remaining term is the probability of a very short successful amplitude cluster. No novelty claim.

---

## 1. Raw finite-grid occupation-Palm estimator is bounded

For the Step-33 first cluster moment,

```math
E[C_\Delta]
=m_a E_{Q_a}[S/L],
\qquad
m_a=\ell Q(a),
```

with

```math
a=u-\Delta.
```

The numerical helper evaluates the per-path contribution

```math
Y=m_a\frac{S}{L}.
```

Its `component_duration()` routine explicitly enforces

```math
L\ge\frac{\delta_t}{2}.
```

Therefore the implemented finite-grid estimator satisfies the exact support bound

```math
\boxed{
0\le Y\le B,
\qquad
B=\frac{2m_a}{\delta_t}.
}
```

This is a finite-grid statement. It is not a continuum lower bound on physical excursion duration.

---

## 2. Empirical Bernstein bound

For independent `Y_i in [0,B]`, let

```math
\bar Y=\frac1n\sum_iY_i
```

and let `s_n^2` be the ordinary unbiased sample variance. Scaling the empirical Bernstein inequality of Maurer and Pontil gives, with probability at least `1-delta_conf`,

```math
\boxed{
E[Y]
\le
\bar Y
+\sqrt{\frac{2s_n^2\ln(2/\delta_{conf})}{n}}
+\frac{7B\ln(2/\delta_{conf})}{3(n-1)}.
}
```

Primary source: A. Maurer and M. Pontil, *Empirical Bernstein Bounds and Sample-Variance Penalization*, COLT 2009 / arXiv:0907.3740.

This is a genuine finite-sample probability statement for the finite-grid estimator; unlike the previous `1.645 SE` allowance, it does not assume a normal sampling distribution.

## 4. NEGATIVE RESULT — direct empirical Bernstein is useless here

At one-sided failure probability

```text
delta_conf = 0.05,
```

the two empirical-Bernstein terms are approximately

```text
sample-variance term / alpha   ~= 0.01165
range term / alpha             ~= 0.23373
------------------------------------------------
total radius / alpha           ~= 0.24538.
```

Therefore the rigorous finite-sample upper confidence bound would be approximately

```math
\boxed{
E[C_\Delta]/\alpha
\lesssim
0.98968+0.24538
\approx1.2351,
}
```

before adding any timing-grid bias allowance.

This does not certify fast feasibility.

If a 95% familywise budget were divided across 17 high-band nodes (`delta_conf=0.05/17`), the same raw endpoint radius becomes roughly

```text
0.429 alpha.
```

**NEGATIVE RESULT:** replacing the Gaussian standard-error allowance by a textbook empirical-Bernstein bound on the existing raw occupation-Palm estimator makes the certificate dramatically worse.

## 5. Why the failure occurs

The observed variance term is not the problem. At 95%, it contributes only

```text
~0.0117 alpha.
```

The dominant correction is

```math
\frac{7B\ln(2/\delta_{conf})}{3(n-1)},
```

which is generated by the formal possibility

```text
L ~= delta_t/2.
```

For comparison, after retaining the existing conservative endpoint grid allowance

```text
0.002 alpha,
```

the central endpoint estimate has only

```text
1 - 0.98968 - 0.002 = 0.00832
```

of normalized margin left.

The raw empirical-Bernstein **range term alone** cannot fall below `0.00832 alpha` at 95% until approximately

```math
\boxed{
n\gtrsim1.40\times10^6.
}
```

Using the present observed variance merely as a planning scale, the full radius would reach `0.00832 alpha` only around

```text
n ~ 1.8e6.
```

The latter number is not a theorem because the future sample variance is unknown; the range-term threshold is a direct consequence of the bound.

---

## 6. REJECTED SHORTCUT

The Step-33 estimator was designed for variance reduction, and empirically it succeeds: the standard error is only `0.00429 alpha` with `50000` paths.

But low empirical variance does **not** by itself imply a sharp distribution-free finite-sample confidence bound when the formal support is thousands of observed standard deviations wide.

Therefore:

```text
low Monte Carlo SE
!=
rigorous finite-sample certificate
```

for this inverse-duration importance estimator.

**REJECTED SHORTCUT:** simply substituting empirical Bernstein, Hoeffding, or another generic bounded-variable inequality for `1.645 SE` does not close the node-statistics gap.

## 7. Duration-truncated decomposition

The range obstruction can be isolated physically.

Choose a deterministic duration threshold

```math
L_0>\delta_t/2.
```

Split successful clusters into

```text
long:  L >= L_0
short: L <  L_0.
```

Let `C_long` and `C_short` be their counts. Since the false-alarm event is `{C_long+C_short>=1}`, the union bound gives the exact decomposition

```math
\boxed{
P_{FA}
\le
E[C_{long}]
+P(C_{short}\ge1).
}
```

The long-cluster occupation-Palm contribution is

```math
Y^{(L_0)}
=m_a\frac{S}{L}1_{\{L\ge L_0\}},
```

and now has the much smaller exact support

```math
\boxed{
0\le Y^{(L_0)}\le B_0,
\qquad
B_0=\frac{m_a}{L_0}.
}
```

For the illustrative choice

```text
L_0 = 0.02,
```

we get

```text
B_0 ~= 3.3943e-5
B/B_0 = 40.
```

At `n=50000`, `delta_conf=.05`, the empirical-Bernstein range penalty drops from

```text
0.23373 alpha
```

to

```math
\boxed{0.00584 alpha.}
```

The existing `50000` paths are still not automatically enough because the variance term remains, but the catastrophic range penalty has disappeared.

Using the present raw standard deviation only as a planning proxy, a long-cluster run with `L_0=.02` reaches the existing endpoint margin at roughly `O(1.6e5)` paths instead of `O(1.8e6)`. A new run is required to know the actual truncated variance.

---

## 8. First nontrivial consequence

The remaining node-statistics problem is **not primarily Monte Carlo normality**.

It is the rare possibility of an extremely short successful lower-level excursion, because that creates the large inverse-duration importance weight.

A rigorous node certificate should therefore be split into

```math
\boxed{
P_{FA}
\le
\underbrace{E[C_{long}]}_{\text{bounded-weight Monte Carlo}}
+
\underbrace{P(C_{short}\ge1)}_{\text{Gaussian short-time excursion bound}}.
}
```

This is better matched to the physics than forcing one generic concentration inequality to absorb both effects.

The short-cluster term is especially structured: a successful cluster of duration `<L_0` must traverse the fixed amplitude gap

```math
\Delta=0.15
```

within a time shorter than `L_0`. It can therefore be attacked directly as a Gaussian short-time oscillation/modulus event.

## 10. Stopping point

Direct distribution-free concentration of the raw inverse-duration Palm estimator is quantitatively too weak. Duration truncation converts the statistical problem into a bounded long-cluster estimator plus a separate rare short-time Gaussian excursion event.
