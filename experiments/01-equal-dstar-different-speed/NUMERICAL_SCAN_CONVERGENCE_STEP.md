# Step 13 — Numerical Correlated-Scan Prototype and Continuous-Maximum Obstruction

**Date:** 2026-08-11 13:50 EDT  
**Status:** DERIVED / NUMERICAL DIAGNOSTIC / REJECTED PRELIMINARY ESTIMATE. A direct Monte Carlo computation of the exact *discretized* correlated Gaussian timing scan was implemented without any independent-trials approximation. It reproduces the broad fast/slow regime structure, but the apparent crossover moves materially as the timing grid is refined. The reason is derived exactly: the hard finite-duration matched filter produces a cusp in the timing covariance, making the continuous scan locally Brownian-like and nondifferentiable for every finite filter duration. Therefore a naive discrete-grid maximum is not yet a controlled approximation to the continuous supremum near the crossover. No exact continuous-time crossover value is claimed.

## 1. Question

Can the finite-duration Gaussian scan with covariance `R_x` be evaluated numerically accurately enough to map

```math
\Gamma(x,\ell,\alpha),
```

solve the fast/slow crossover equation, and produce a genuine task phase diagram without replacing the correlated timing search by an uncontrolled effective number of independent trials?

The first numerical attempt answers:

```text
broad regime map: yes
continuous crossover location with naive time-grid maxima: not yet
```

The failure mode is understood analytically and is scientifically useful.

## 2. Exact finite-duration process used in the simulation

For the Step-09/11 family in white output noise, define the dimensionless finite matched-filter template

```math
h_x(v)=v e^{-v}\,1_{[0,x]}(v).
```

Let

```math
E_x=\int_0^x v^2e^{-2v}dv
=\frac14\eta(x),
```

with

```math
\eta(x)=1-e^{-2x}(1+2x+2x^2).
```

The normalized continuous noise-only timing scan can be represented as the moving average

```math
\boxed{
z_x(u)
=\frac{1}{\sqrt{E_x}}
\int_0^x h_x(v)\,dW(u+v),
}
```

where `W` is a two-sided Wiener process / white-noise integral.

Its exact covariance is

```math
\boxed{
R_x(y)
=\frac{\int_0^{x-y}v(v+y)e^{-2v-y}dv}{E_x},
\qquad 0\le y<x,
}
```

and `R_x(y)=0` for `y>=x`.

No independent timing slots enter this construction.

## 3. Discretized Monte Carlo method

Choose dimensionless timing step `delta`.

Midpoint-discretize the filter:

```math
v_j=(j+1/2)\delta,
```

```math
h_j=v_j e^{-v_j}.
```

Generate independent standard Gaussian white-noise increments

```math
\xi_k\sim N(0,1)
```

and form the normalized moving-average scan

```math
\boxed{
z_k
=\frac{\sum_j h_j\xi_{k+j}}
{\sqrt{\sum_j h_j^2}}.
}
```

For a dimensionless monitoring interval `ell`, the discrete scan statistic is

```math
Z_{x,\ell,\delta}
=\max_{0\le k\delta\le\ell}z_k.
```

The empirical `(1-alpha)` quantile estimates

```math
\Gamma_\delta(x,\ell,\alpha).
```

This is an exact Monte Carlo simulation of the *grid-sampled correlated process* generated by the finite matched filter. It is not an effective-`M` approximation.

The implementation uses FFT convolution in batches. A reproducible script is stored under

```text
numerics/correlated_scan_mc.py
```

for this experiment.

## 5. What the coarse calculation showed

The broad qualitative behavior agreed with Step 12:

```text
small timing uncertainty -> fast detector clearly wins
increasing timing uncertainty -> fast advantage shrinks
near fast feasibility edge -> required fast decision time rises sharply
```

For the validation parameters, coarse scans placed the crossover near slow-detector dimensionless timing uncertainty `ell_s ~ 49`.

However, refinement showed that this number was not converged.

### Diagnostic only — not accepted crossover values

With timing-grid spacing

```text

```

and roughly `3e4–4e4` paths in the local refinement, the apparent crossover was bracketed around


With


```text

```

## 6. Exact reason for the slow grid convergence: covariance cusp

The finite-duration template has

```math
h_x(0)=0,
```

but for finite `x`,

```math
h_x(x)=xe^{-x}\ne0.
```

For `y>=0`, write the unnormalized covariance

```math
C_x(y)=\int_0^{x-y}h_x(v)h_x(v+y)dv.
```

Differentiate at zero from the right:

```math
C_x'(0^+)
=-h_x(x)^2
+\int_0^x h_x(v)h_x'(v)dv.
```

Since

```math
\int_0^x h h'\,dv
=\frac12[h(x)^2-h(0)^2],
```

and `h(0)=0`,

```math
\boxed{
C_x'(0^+)=-\frac12h_x(x)^2.
}
```

Normalize by `E_x`:

```math
\boxed{
R_x'(0^+)
=-\frac{h_x(x)^2}{2E_x}.
}
```

Using

```math
E_x=\frac14\eta(x),
```

obtain

```math
\boxed{
a_x\equiv-R_x'(0^+)
=\frac{2x^2e^{-2x}}{\eta(x)}.
}
```

Therefore the even covariance has a cusp:

```math
\boxed{
R_x(y)=1-a_x|y|+O(y^2).
}
```

For example,

```text
x=3 -> a_x ~ 4.76e-2
x=4 -> a_x ~ 1.09e-2
x=5 -> a_x ~ 2.28e-3
x=6 -> a_x ~ 4.43e-4
```

The cusp becomes weak for long filters but is nonzero for every finite hard cutoff.

## 7. Local roughness of the scan

For a unit-variance stationary Gaussian process,

```math
E[(z(u+h)-z(u))^2]
=2[1-R_x(h)].
```

Using the cusp expansion,

```math
\boxed{
E[(z(u+h)-z(u))^2]
\sim 2a_x|h|.
}
```

Thus increments scale as

```math
|z(u+h)-z(u)|_{rms}
\sim\sqrt{2a_x|h|}.
```

The finite-duration hard-window scan is therefore locally Brownian-like / mean-square nondifferentiable.

This is qualitatively different from the full-template limit

```math
R_\infty(y)=(1+|y|)e^{-|y|}
=1-\frac12y^2+O(|y|^3),
```

which is differentiable at zero.

The limit is nonuniform:

```text
for every finite x -> cusp / rough scan
x -> infinity first -> smooth full-template scan
```

This explains why the Step-08 smooth-process Rice formula cannot simply be inserted into the exact finite-hard-window calculation.

## 8. Why the discrete maximum is biased low

A grid evaluates

```math
\max_k z(k\delta)
```

rather than

```math
\sup_u z(u).
```

For the rough finite scan, between-grid fluctuations are of RMS order `sqrt(delta)`, not order `delta` as they would be for a differentiable process.

Therefore grid refinement can continue to expose previously missed local maxima at a relatively slow rate. The empirical global threshold rises as the continuous supremum is resolved more faithfully.

Near the fast detector's feasibility boundary, the detection-time function is very steep: a small threshold error can create a large error in the inferred `X_D` and hence a large shift in the crossover location.

This combination explains the observed numerical instability.

---

## 9. Numerical conclusion of Step 13

**DERIVED / NUMERICAL DIAGNOSTIC:** direct correlated-process Monte Carlo is sufficient to confirm the broad Step-12 regime structure, but a naive fixed timing grid is not yet sufficient to quote a trustworthy continuous-time crossover.

The failure is not due to insufficiently many independent timing samples or to an incorrect covariance model. It is a continuum-resolution problem created by the exact hard-deadline filter itself.

The preliminary `ell_x ~ 49` values are therefore explicitly invalidated as final results.
